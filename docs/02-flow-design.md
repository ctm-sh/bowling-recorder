# 02. 사용 흐름·디자인

## 원칙
- **모바일 우선.** 모든 화면은 휴대폰 폭(360~430px) 기준으로 설계한다. PC에서는 같은 화면을 가운데 정렬로 보여준다.
- 하단 탭
  - 회원(기본): 홈 · 결과 · 내 기록 · 랭킹
  - 운영진 로그인 후: 홈 · 정모 · 회원 · 설정 (조회 화면은 홈에서 그대로 볼 수 있음)
- 주요 버튼은 화면 하단에 고정해서 엄지로 누르기 쉽게 한다.

## 핵심 시나리오
**S1. 정모 시작 (현장)**
새 정모 → 참석자 11명 체크 (최근 참석자가 위에 표시) → 1게임 팀 구성에서 형태 선택 (4v4v3 추천) → 랜덤 배정 (에버가 비슷한 사람끼리 나눠 배정, 팀 핸디 합계 표시) → 확정.

**S2. 게임 종료 → 정산 (현장)**
점수 입력 → 결과 스코어보드에서 순위와 패배 팀의 1인 부담금 확인 → "팀 그대로" 또는 "새로 섞기"로 다음 게임 → 정모 마감 → 사람별 정산 텍스트를 카톡에 복사 → 구글 시트 자동 반영.

**S3. 티어 심사 (휴대폰, 이동 중)**
회원 탭에서 "승급 후보" 표시 확인 → 회원 상세에서 전체 에버, 최근 20게임 폼, 상대 전적 확인 → 승인하고 사유 입력 → 이력 저장.

**S4. 회원이 결과 확인 (회원 휴대폰, 정모 직후·다음 날)**
단톡에 올라온 링크를 연다 → 처음이면 "나는 누구"에서 자기 이름을 고른다 → 홈에 오늘 내 점수, 팀 순위, 낼 금액이 보인다 → 결과 탭에서 게임별 전체 점수표를 본다 → 내 기록에서 승률과 "나의 상대방"별 전적(점수+핸디 비교)을 확인한다.

## 화면 구조
```
[회원·로그인 없음]  첫 방문: 이름 선택 (기기에 저장, 언제든 변경)
  [홈] 오늘/최근 정모 내 요약 (점수, 팀 순위, 낼 금액)
  [결과] 정모 목록 ─▶ 정모 상세 (게임별 순위 B, 전체 점수표, 정산)
  [내 기록] 에버·최근 폼·승률 ─▶ 상대별 전적 (192+12 vs 201+0)
  [랭킹] 전체 회원 에버·승률 순위
  하단 작은 링크 "운영진 로그인"

[운영진] 로그인 ─▶ 홈 (진행 중 정모 / 최근 정모)
  [정모] 참석 체크 ─▶ 팀 구성(A) ─▶ 점수 입력(A) ─▶ 결과(B) ─┐
                         ▲──────── 팀 그대로 / 새로 섞기 ─────┘
                       결과(B) ─▶ 정모 마감 ─▶ 정산 요약 (복사 / 시트 반영)
  [회원] 목록 (후보 배지) ─▶ 상세 (에버·폼·상대 전적·티어 이력) ─▶ 티어 변경 + 사유
  [설정] 핸디표 · 게임비 · 최근 N게임 · 구글 시트 연동 · 기존 엑셀 가져오기
```

## 선택한 디자인: A + B 하이브리드
| 화면 | 시안 | 표현 |
|---|---|---|
| 참석 체크, 팀 구성, 점수 입력 | **A (단계형 미니멀)** | 흰 바탕, 남색 포인트, 상단 단계 표시(팀구성 → 점수 → 결과), 팀별 카드 세로 나열, 큰 숫자 입력칸, 하단 고정 버튼 |
| 결과, 정산 요약 | **B (전광판)** | 어두운 배경, 팀별 네온 색(주황·하늘·연두·분홍), 상단 순위 스코어보드, 팀 카드 좌우 스와이프, 패배 팀 💸와 1인 부담금 강조 |
| 회원, 설정, 내 기록, 랭킹 | A 톤 | 목록과 카드 |
| 회원용 정모 결과 | B 톤 | 운영진 결과 화면과 같은 스코어보드를 조회 전용으로 |

- 점수 입력칸은 숫자 키패드(`inputmode="numeric"`)를 쓰고, 입력하면 다음 사람으로 자동 이동한다.
- 팀 구성 화면에서 이름을 길게 눌러 다른 팀으로 옮길 수 있다.
- 결과 화면 하단에는 [팀 그대로 ↻] [새로 섞기 🎲] [정모 마감] 버튼을 둔다.
